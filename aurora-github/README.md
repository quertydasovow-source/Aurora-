# Aurora — персональный маршрут поступления

AI-сервис для школьников **9–12 класса** в Казахстане, которые выбирают **бакалавриат** в Казахстане, Венгрии и Нидерландах.

Проект для [LOCUS Startup Hackathon 2026](https://aistartify.com), **кейс №2** «Персональный маршрут поступления».  
Код участия / промокод сабмита: **`LOCUSCASE2`**.

Интерфейс на русском. Это не чат и не каталог ссылок: код отбирает программы по проверенному каталогу, Groq (если задан ключ) пишет объяснения. Процент «шанса поступления» не считается.

---

## Задача

Абитуриенту нужен маршрут, а не ещё один список вузов. Решения разрознены: направление, страна, экзамены, документы, бюджет, дедлайны. Рекомендации часто общие, и непонятно, что делать сейчас.

## Решение

Aurora проводит по одному связному пути:

1. **Вход** — зачем сервис и какой результат получишь.
2. **Анкета** — класс, направление, оценки, ЕНТ / IELTS / SAT / TOEFL, страна, язык, бюджет.
3. **Диагностика** — на что опереться, что подготовить, что уточнить.
4. **Рекомендации** — программы со статусом и объяснением «почему».
5. **Сравнение** — два и больше вариантов.
6. **План** — экзамены, документы, сроки, советы.
7. **Следующий шаг** — одна ближайшая задача и отметки прогресса.

Прогресс хранится в браузере (`localStorage`). Аккаунт и Firebase не нужны. «На главную» ответы не стирает. Стирает только «Начать заново» после подтверждения.

## Архитектура

```
браузер (Vite / React)
  анкета, маршрут, план, localStorage
        │
        ▼  POST /api/recommendations
Express (server/index.mjs)
  1. код фильтрует catalog.json
  2. Groq получает уже отобранные карточки и пишет текст
  3. сервер проверяет JSON: чужие id и выдуманные курсы отбрасываются
```

| Путь | Назначение |
| --- | --- |
| `src/App.tsx`, `src/storage.ts` | путь пользователя и сохранение |
| `src/components/` | главная, анкета, маршрут, план, усиление профиля |
| `src/data/catalog.json` | 15 программ, 30 полей, URL источников |
| `src/lib/recommendations/` | фильтр, экзамены, статусы, план |
| `server/index.mjs` | API, Groq, кэш, fallback без ключа |
| `server/recommendations.test.mjs` | автопроверки каталога и правил |

Ключ Groq нельзя класть в браузер и в переменные `VITE_*`.

## Как устроены рекомендации и AI

1. Код (`filterPrograms.ts`) отбирает записи каталога: направление, страна, уровень, год, бюджет, язык, ЕНТ, IELTS/TOEFL/SAT, архив, дедлайны.
2. Код ставит статус: подходит / нужна подготовка / нужно уточнить / сейчас не подходит. Это не вероятность поступления.
3. На сервер уходит профиль без имени и контактов плюс уже отобранные карточки.
4. Groq вызывается после анкеты, при выборе целевой программы или при смене важных ответов. Не вызывается при переключении вкладок.
5. Модель возвращает JSON. Сервер оставляет только id из каталога и не принимает выдуманные ссылки на курсы.
6. Если Groq недоступен, подбор всё равно строится; интерфейс честно пишет, что AI-пояснения временно нет.

Факты о ценах, сроках и требованиях берутся **только** из каталога.

## Запуск

Нужны **Node.js 20+** и npm.

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173**.  
API: **http://localhost:8787** (`GET /api/health`, `POST /api/recommendations`).

Продакшен-сборка (сайт с того же Express):

```bash
npm run build
npm start
```

После сборки откройте **http://localhost:8787**.

Проверки:

```bash
npm test
npm run build
```

### Ключ Groq (необязательно для подбора)

1. Скопируйте `server/.env.example` в `server/.env`.
2. Вставьте ключ локально:

```
GROQ_API_KEY=ваш_ключ
GROQ_MODEL=openai/gpt-oss-20b
PORT=8787
```

3. **Не коммитьте** `.env` и `server/.env` — они в `.gitignore`.

Без ключа маршрут работает. Объяснения тогда собираются правилами.

## Тестовый сценарий для жюри

1. Главная → «Построить мой маршрут» или демопрофиль (например IT / Нидерланды).
2. Пройти анкету до маршрута. На обзоре должен быть **следующий шаг**. На карточках — **почему такой статус** и **почему подходит**.
3. Выбрать две программы → вкладка «Сравнение». Назначить одну целью плана. Отметить задачу.
4. Нажать «Изменить ответы»: сменить **бюджет, страну или экзамен** → список и объяснения обновляются.
5. «На главную» → «Продолжить заполнение» / «Открыть мой маршрут». Обновить страницу — анкета на месте.
6. Узкое окно (~360 px): путь читается, кнопки доступны.
7. Если Groq без ключа или перегружен — серая плашка про запасные объяснения, подбор программ остаётся.

Логин и пароль не нужны.

## Ограничения

- Каталог небольшой: по узкому профилю может быть меньше трёх подтверждённых программ — это честно, выдуманные вузы не добавляются.
- Доп. советы по курсам общие, пока нет проверенного каталога активностей.
- Бесплатный лимит Groq может отключить AI-текст; подбор правилами остаётся.
- Нет публичного деплоя в этом репозитории по умолчанию: жюри запускает по инструкции выше. Когда появится сайт — вставьте ссылку сюда:

**Рабочий сайт:** _вставить URL после деплоя_  
**Тестовый вход:** не требуется

## Техническая справка

Кратко для формы AIstartify и жюри.

- **Модель:** Groq `openai/gpt-oss-20b`, JSON Schema, `reasoning_effort: low`.
- **Проверка ответа:** `server/recommendations/validateRecsJson.mjs` — только id из текущего пула, без произвольных URL.
- **Безопасность:** ключ не в клиенте; `.env` в gitignore; лимит запросов на IP; Groq не выполняет инструкции из текста анкеты (данные отдельно от system prompt).
- **Состояние:** `localStorage`, ключ `aurora-admission-state-v3`.
- **Честность:** нет гарантий поступления, нет неподтверждённых дедлайнов как факта, нет конвертации валют «на глаз».
- **Тесты:** `npm test` — каталог, статусы «исключить», бюджет, SAT/TOEFL как альтернативы, пустой каталог курсов.
