# Что отправить на AIstartify

Капитан команды заполняет форму на [aistartify.com](https://aistartify.com) до **19 сентября 2026, 12:00 (Астана)**.  
Проекты в Instagram, почте или только в LOCUS Hackathons **не считаются** поданными.

## Поля карточки

Скопируйте и подставьте свои имена / ссылки.

- **Название команды:** _указать_
- **Название проекта:** Aurora
- **Промокод / код участия:** `LOCUSCASE2`
- **Краткое описание:** Aurora превращает анкету школьника 9–12 класса в маршрут бакалавриата: подходящие программы с объяснением «почему», сравнение, план и один следующий шаг. Факты только из каталога, без процента шанса поступления.
- **Целевой пользователь:** школьник Казахстана, бакалавриат в Казахстане, Венгрии и Нидерландах.
- **Рабочий продукт:** _ссылка на сайт_ (если сайта ещё нет — жюри запускает `npm install` → `npm run dev` по README; всё равно лучше выложить Render / Railway).
- **GitHub:** _ссылка на репозиторий_
- **Демо-видео:** _ссылка, до 3 минут_
- **Презентация:** PDF до 8 слайдов (текст в `docs/slides.md`)
- **Тестовый логин:** не нужен

## Видео до 3 минут

1. Проблема: поступление — маршрут, не список вузов (15 сек).
2. Анкета → обзор → программы с «почему» → сравнение → план и следующий шаг (живой экран).
3. Смена страны / бюджета / экзамена — список меняется.
4. Итог: честный каталог + Groq только для текста.

Не читать слайды целиком. Показывать клики.

## Презентация

Откройте `docs/slides.md` → Google Презентации или PowerPoint → Файл → скачать PDF. Не больше 8 слайдов.
