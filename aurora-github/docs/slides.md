# Aurora — слайды для PDF (ровно 8)

Скопируйте каждый блок `##` на отдельный слайд. Экспорт: PDF, без мелкого текста на скрине.

## 1. Проблема

Поступление — десятки решений: страна, вуз, экзамены, документы, бюджет, дедлайны.

Абитуриенту нужен **маршрут**, а не ещё один список университетов.

## 2. Решение

**Aurora** — сервис для школьников 9–12 класса: бакалавриат в Казахстане, Венгрии и Нидерландах.

Короткая анкета → подходящие программы с объяснением → сравнение → план и один ближайший шаг.

## 3. Путь пользователя

Главная → анкета → обзор → программы → сравнение → мой план.

Всегда видно, где ты и что делать дальше. Прогресс сохраняется в браузере.

## 4. Персонализация

Подбор связан с направлением, страной, бюджетом и экзаменами.

Смена ответа пересчитывает маршрут. SAT у NU не требуется всем. IELTS и TOEFL могут быть альтернативами.

## 5. Честные данные

Каталог — единственный источник цен, сроков и требований.

Нет выдуманных вузов, курсов и процента «шанса поступления». Если срок неизвестен — так и написано. Источники на карточке.

## 6. Технология

React + Express. Код отбирает программы. Groq пишет объяснения по уже проверенным карточкам.

Без ключа подбор работает. Ключ не попадает в браузер.

## 7. Команда и отличие

Свой продукт и своя визуальная система. Не копия LOCUS.
