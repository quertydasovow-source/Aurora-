# Что отправить на AIstartify

Капитан заполняет форму на [aistartify.com](https://aistartify.com). Проекты только в Instagram, почте или LOCUS Hackathons не считаются поданными.

Этот репозиторий закрывает поля **рабочий продукт (локальный запуск / URL)**, **GitHub** и **README / техническая справка**. Демо-видео и презентация в этот пакет не входят — их команда добавляет отдельно, если требует форма.

## Поля карточки

- **Название команды:** _указать_
- **Название проекта:** Aurora
- **Промокод / код участия:** `LOCUSCASE2`
- **Краткое описание:** Aurora превращает анкету школьника 9–12 класса в маршрут бакалавриата: подходящие программы с объяснением «почему», сравнение, план и один следующий шаг. Факты только из каталога; Groq не определяет официальные требования.
- **Целевой пользователь:** школьник 9–12 класса, бакалавриат в Казахстане, Венгрии и Нидерландах.
- **Рабочий продукт:** _ссылка на сайт_ (если сайта ещё нет — жюри запускает `npm install` → `npm run dev`; логин не нужен).
- **GitHub:** _ссылка на репозиторий с кодом_
- **Тестовый логин:** не нужен

## Не класть в GitHub

- `node_modules`
- `dist`
- `.env`, `server/.env`, любой файл с настоящим `GROQ_API_KEY`
- личные скриншоты с открытой вкладкой Groq API Keys
